# Earning Robot

A Chromebook-friendly foundation for an autonomous work/opportunity agent.

## Vision
- Monitor approved opportunity sources
- Monitor connected email
- Analyze requirements
- Prepare proposals and work
- Manage clients, tasks and payments
- Keep an auditable activity log
- Run scheduled background jobs

## Safety
This project is designed for legitimate automation. It must not mass-spam, create fake accounts, bypass platform restrictions, or send unauthorized applications.

## Current phase
Phase 1: advanced control-center UI and architecture foundation.

Next phases:
1. Persistent data layer and job/event model
2. Email connector
3. Approved opportunity-source connectors
4. AI task/proposal engine
5. Scheduled worker
6. Client/order/payment workflows
7. PWA/Chromebook install and notifications

Never commit API keys or passwords. Use environment variables/secrets.
